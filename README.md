# 🏥 Hospital Emergency Room (ER) Analytics Dashboard

An interactive **Microsoft Excel dashboard** designed to analyze and monitor **Hospital Emergency Room (ER) operations, patient demographics, waiting times, admissions, referrals, and patient satisfaction**.

The dashboard transforms healthcare data into clear and interactive visual insights, helping users understand ER activity and identify operational patterns.

---

## 📌 Project Overview

Managing emergency room operations requires clear visibility into patient volume, waiting times, admission patterns, department referrals, and patient experience.

This **Hospital Emergency Room Analytics Dashboard** provides an interactive view of these key areas through Excel-based data analysis and visualization.

Users can filter the dashboard by:

* 📅 Year — **2023 and 2024**
* 📆 Month — **January to December**

The dashboard updates dynamically based on the selected filters.

---

## 🎯 Project Objectives

The main objectives of this project are to:

* Analyze emergency room patient volume.
* Monitor average patient waiting time.
* Understand patient satisfaction levels.
* Analyze patient attendance and delays.
* Examine admission patterns.
* Understand patient demographics by gender and age group.
* Analyze department referral patterns.
* Provide an interactive dashboard for quick decision-making.

## 📊 Key Performance Indicators (KPIs)

The dashboard provides the following high-level performance indicators:

| KPI                            |          Value | Description                                                                    |
| ------------------------------ | -------------: | ------------------------------------------------------------------------------ |
| **Total Patients**             |        **999** | Total number of emergency room visits in the selected period.                  |
| **Average Wait Time**          | **35.15 mins** | Average time between patient check-in/triage and initial medical consultation. |
| **Patient Satisfaction Score** |  **5.15 / 10** | Average patient satisfaction rating.                                           |

> **Note:** KPI values change based on the selected year and month filters.

## 🔎 Dashboard Features

### 📅 Interactive Time Filters

The dashboard includes interactive slicers that allow users to filter the analysis by:

* **Year:** 2023, 2024
* **Month:** January – December

This allows users to analyze overall performance as well as specific periods.

### 📌 Dynamic KPI Cards

The dashboard displays key metrics in an easy-to-read format, including:

* Total Patients
* Average Wait Time
* Patient Satisfaction Score

These metrics dynamically respond to the selected filters.

## 📈 Data Visualization & Analysis

### 1. Patient Attendance Status

A doughnut chart shows whether patients were attended **on time or with a delay**.

* **On-Time:** 41%
* **Delayed:** 59%

This visualization helps identify the proportion of patients experiencing delays.

---

### 2. Gender-Wise Patient Distribution

The dashboard analyzes the distribution of patients by gender:

* **Female:** 52%
* **Male:** 48%

This provides a quick overview of the gender composition of ER patients.

---

### 3. Admission Status

The admission analysis compares patients who were admitted with those who were not admitted.

| Admission Status | Patients | Percentage |
| ---------------- | -------: | ---------: |
| **Admitted**     |      495 |     49.55% |
| **Not Admitted** |      504 |     50.45% |

This provides an overview of ER utilization and admission patterns.

---

### 4. Age Group Analysis

A column chart presents the distribution of patients across different age groups.

The dashboard includes age groups ranging from:

* 0–09
* 10–19
* 20–29
* 30–39
* 40–49
* 50–59
* 60–69
* 70–79

This helps identify the age groups contributing most to ER visits.

---

### 5. Department Referral Analysis

A horizontal bar chart shows the number of patients referred to different departments.

The dashboard covers referrals including:

* General Triage / None
* General Medicine / Practice
* Orthopedics
* Physiotherapy
* Neurology
* Cardiology
* Gastroenterology
* Renal

This helps visualize the workload and referral patterns across departments.
